# Search Plugins

This repository contains search plugins used by the search feature in [qBittorrent](https://github.com/qbittorrent/qBittorrent).

> [!IMPORTANT]
> Use the plugins and the websites they connect to at your own risk. \
> You are personally responsible for following the copyright laws and other applicable laws in your country.

## Contribute

We currently lack the capacity to maintain additional official plugins.
However, pull requests to fix existing ones are highly welcome.

This repository is maintained by community contributors.
It is not directly managed by the qBittorrent core team. \
Its purpose is to provide a hub for third-party contributors to gather and share their plugins.
